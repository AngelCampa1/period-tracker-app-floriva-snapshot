# TTC Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Productize TTC mode as a calm, local daily-context experience across setup, Today, logging, insights, and simulator QA.

**Architecture:** Add one reusable TTC observation formatter that turns existing local `ttcObservation` fields into neutral summaries. Surface that formatter in Today and Insights without schema changes, and add setup preview copy through the existing onboarding/settings TTC routes.

**Tech Stack:** Expo Router, React Native, TypeScript, SQLite repositories, Jest/RNTL, Detox.
