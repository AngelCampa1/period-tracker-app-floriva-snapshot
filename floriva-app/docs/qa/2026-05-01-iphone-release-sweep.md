## Issues Found And Fixed

1. Tracked native build artifacts exhausted local disk during a clean worktree QA baseline.
   - Impact: Jest cache writes and iOS build steps failed with `ENOSPC`; the repo had more than 30,000 generated `ios/build-storekit` files tracked.
   - Root cause: `ios/build-storekit/` was committed and not ignored.
   - Fix: removed `ios/build-storekit/` from Git tracking, added `/ios/build-storekit/` to `.gitignore`, and added a sanity test that fails if generated native build outputs are tracked again.
   - Regression: `tests/sanity/native-build-artifacts.test.ts`.
   - Verification: `pnpm jest tests/sanity/native-build-artifacts.test.ts --runInBand --cacheDirectory .jest-cache`.

2. The floating tab dock covered route content on iPhone.
   - Impact: first-visible Calendar and Settings states hid or clipped content behind the dock, including "Recent history" and billing rows.
   - Root cause: both the native tab container and the custom dock container were `position: 'absolute'`, so React Navigation did not reserve screen space for the dock.
   - Fix: returned the tab bar and dock container to normal layout flow while preserving the glass dock styling and hit targets.
   - Regression: `tests/app/app-tab-layout.test.tsx`, `tests/features/app-shell/UnifiedGlassTabBar.test.tsx`.
   - Verification: targeted Jest tests, `qa-rich-history-calendar-after-tabbar-fix.png`, `qa-rich-history-today-after-tabbar-fix.png`.

3. Detox fresh-onboarding smoke was blocked by Expo dev-client onboarding.
   - Impact: `pnpm detox:test:ios` timed out while waiting for onboarding because the native dev-menu intro sheet appeared over Floriva and synchronization waited on the dev-client run loop.
   - Root cause: the dev-client intro can appear after the dev URL/deep-link handoff, and the test helper dismissed it too early.
   - Fix: marked the Expo dev-menu onboarding as completed for debug builds at startup and added the dev-client `disableOnboarding=1` launch parameter. The e2e helper also disables synchronization before connecting the dev client.
   - Regression: `e2e/smoke.e2e.js`.
   - Verification: `EXPO_DEV_SERVER_PORT=8081 DETOX_IOS_DEVICE='iPhone 17 Pro' pnpm detox:test:ios`.

4. Clean iOS worktree build needed dependency setup.
   - Impact: first `pnpm detox:build:ios` failed because CocoaPods support files were absent in the fresh worktree.
   - Root cause: `ios/Pods` is correctly ignored and must be installed locally before a clean native build.
   - Fix: ran `pod install` in `ios/`; `Podfile.lock` updated the Hermes checksum generated by the local install.
   - Regression: covered by the required iOS build command.
   - Verification: `EXPO_DEV_SERVER_PORT=8081 DETOX_IOS_DEVICE='iPhone 17 Pro' pnpm detox:build:ios`.

5. Detox selectors were ambiguous on stacked onboarding routes.
   - Impact: the fresh-onboarding smoke could fail on iPhone with duplicate `Back` or continue controls exposed by the native navigation stack.
   - Root cause: the e2e helper matched user-facing text or the first matching test ID even when an offscreen route exposed the same control.
   - Fix: targeted the existing start-path back test ID and added an e2e helper that retries duplicated action IDs until the expected next route is visible.
   - Regression: `e2e/smoke.e2e.js`.
   - Verification: `EXPO_DEV_SERVER_PORT=8081 DETOX_IOS_DEVICE='iPhone 17 Pro' pnpm detox:test:ios`.
