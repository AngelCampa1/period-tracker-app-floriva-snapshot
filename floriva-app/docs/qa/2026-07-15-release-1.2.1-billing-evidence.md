# Floriva 1.2.1 Billing Evidence

Release identity: iOS `1.2.1 (20)` and Android `1.2.1 (20)`.

This record separates completed transaction evidence from configuration audits
and environment-blocked checks. A configuration audit is not represented as a
purchase, restore, crossgrade, or offer-redemption transaction.

## Release decision

The release owner authorized the store mutations and the complete 1.2.1 release
workflow in the active release task on 2026-07-15. Submission proceeds with the
completed safety evidence below. Device/account-dependent checks that could not
be completed remain explicit follow-ups; they are not release passes.

The decision is safe for existing subscribers because no subscriber migration,
base-plan replacement, price migration, subscription-group move, or entitlement
rewrite is part of 1.2.1.
